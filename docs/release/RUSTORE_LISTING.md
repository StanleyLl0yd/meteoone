# RuStore listing — deferred to stable release

MeteoOne alpha and beta versions are distributed through GitHub Releases only and are not submitted to RuStore.

This file intentionally contains no active alpha/beta store submission checklist. Store metadata, screenshots, privacy declarations, signing setup and final listing copy will be refreshed from the then-current RuStore requirements during M6/M7 immediately before the first stable RuStore release.

Stable-store policy:

- GitHub Release is created first and always contains signed APK + signed AAB;
- manual APK testing is optional;
- the unchanged stable AAB from that GitHub Release is the candidate for manual RuStore submission;
- repository automation must never upload or publish to RuStore;
- no certificates, PEM files, checksum manifests, mappings or provenance files are user-facing GitHub Release assets.

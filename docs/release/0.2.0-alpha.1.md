# MeteoOne 0.2.0-alpha.1

Feature-complete M3 pre-beta boundary.

## Highlights

- complete three-destination product UI: Forecast, Models, and Settings;
- current conditions, 72-hour hourly forecast, and three-day summary;
- persisted offline model-comparison evidence for ECMWF IFS, DWD ICON, and NOAA GFS;
- provider paths remain grouped under model families instead of becoming duplicate forecast votes;
- Temperature, Precipitation, Wind, and Pressure comparison only when exact-hour source data is genuinely comparable;
- explicit source gaps, model runs, generated times, failed-source identities, and qualitative agreement;
- Settings privacy/offline explanation plus forecast-source attribution;
- Russian and English resource parity enforced by CI;
- adaptive readable-width layout, large-font-safe controls/metadata, real Russian plural forms, and improved accessibility headings/scroll reachability;
- Room v1 -> v2 migration preserves existing fused caches while adding model-comparison evidence;
- approximate/coarse location only, normalized to the 0.1° forecast grid before persistence;
- failed refreshes preserve valid cached forecasts.

## Distribution

This is a GitHub prerelease. The release pipeline must publish exactly:

- `meteoone-0.2.0-alpha.1.apk`
- `meteoone-0.2.0-alpha.1.aab`

Both binaries are built and signed together from the same reviewed canonical `main` SHA.

Alpha and beta versions are GitHub-only. They are not uploaded to RuStore.

## Scope boundary

M4 verification-engine implementation is not included. No calibrated numeric confidence, dynamic verification-backed weights, provider-health backend, or store publication is part of this release.

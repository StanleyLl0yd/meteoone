# MeteoOne 0.1.0-alpha.1

First installable MeteoOne alpha.

## Highlights

- fused hourly forecast through 72 hours;
- multiple weather-model/provider paths behind one forecast;
- offline-first Room cache that survives process restarts and network loss;
- explicit fresh, stale and expired cache states;
- approximate-location flow initiated only by explicit user action;
- location reduced to the privacy-safe 0.1-degree forecast grid before persistence;
- manual refresh that preserves usable cached data when a network/provider refresh fails;
- Russian and English alpha interface.

## Distribution

This is a GitHub prerelease. The release publishes both signed Android artifacts:

- `meteoone-0.1.0-alpha.1.apk`
- `meteoone-0.1.0-alpha.1.aab`

Alpha and beta versions are not submitted to RuStore. Manual APK testing is optional; both APK and AAB are always produced together from the same release source.

M3 product-UI work follows this technical alpha and is not included in this build.
